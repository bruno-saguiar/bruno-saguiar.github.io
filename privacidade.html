Política de Privacidade

Aplicativos Triagem Gmail, Triagem Google Drive e Campus Life — Gmail.
Responsável: Bruno dos Santos Aguiar — bruno.saguiar@gmail.com.

1. Natureza dos aplicativos

São ferramentas de automação de uso estritamente pessoal, executadas no computador do próprio responsável. Não são oferecidas ao público, não têm cadastro de usuários e não prestam serviço a terceiros.

2. Dados acessados

Os aplicativos acessam, mediante autorização OAuth do Google, apenas as contas Google do próprio responsável: mensagens de correio (Gmail) e arquivos (Google Drive). O acesso serve para ler, classificar, copiar e organizar esse conteúdo a pedido do titular da conta.

3. Uso e armazenamento

Os dados são processados localmente, no equipamento do responsável. As credenciais de acesso (tokens) ficam guardadas nesse equipamento e podem ser revogadas a qualquer momento em myaccount.google.com/permissions.

4. Compartilhamento

Nenhum dado é vendido, cedido, transferido ou compartilhado com terceiros. Não há uso para publicidade, perfilamento ou treinamento de modelos.

5. Dados de outras pessoas

Os aplicativos não coletam dados de outras pessoas além do que já consta nas contas do próprio responsável, e não os tratam para nenhuma finalidade distinta da organização pessoal dessas contas.

6. Uso limitado (Google API Services)

O uso das informações recebidas das APIs do Google obedece à Política de Dados do Usuário dos Serviços de API do Google, inclusive aos requisitos de Uso Limitado.
